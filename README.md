# Evercrest Atelier

Single-page watch product landing page built with Vite, React, and TypeScript.

## Current Product Slice

- Image-led hero for a premium watch brand.
- Three-product collection showcase.
- Material highlights and atelier promise section.
- No signup flows, forms, or input fields.

## Setup

```sh
npm install
```

## Run Locally

```sh
npm run dev
```

## Verify

```sh
npm run lint
npm run test
npm run build
```
